# 프리미엄 교육용 다과 추천 Streamlit 앱 v4

사내 교육·워크숍·세미나에서 참가자가 “대접받고 있다”고 느낄 수 있는
프리미엄 개별포장 다과와 브랜드 음료를 추천하는 Streamlit 앱입니다.

## v4 반영 내용

- 인원수 구간 선택과 잠긴 정확 인원 입력을 제거하고 **정확한 인원수 숫자 입력 하나**로 통합
- 음료를 **생수 포함 / 커피 포함 / 그 외 음료 포함** 독립 체크박스로 변경
- 체크박스는 모두 해제 상태에서 시작하며 중복 선택 가능
- 주 연령대를 제거하고 **참가자 성향**으로 변경
  - 달콤하고 간편한 구성
  - 담백함을 더한 균형 구성
  - 둘 다 혼합
- 고급 설정 전체 제거
- 1인 1일 예산을 10,000원으로 고정
- 다과는 1인 1일 평균 3개, 전체 수량 10% 여유
- 오설록·고디바·페레로로쉐·린트·신라명과·워커스·로아커 등 프리미엄 브랜드 중심
- 커피는 스타벅스 병커피·칸타타 콘트라베이스·TOP 등 개당 추정가 1,000원 이상
- 후보 풀은 명시된 예시를 우선해 다음처럼 계산
  - 1일 8종
  - 2일 10종
  - 3일 12종
  - 4일 14종
  - 5일 16종
- 결과 상단에 쿠팡 홈 버튼, 후보 풀과 구매 구성에 쿠팡 검색 링크 제공
- 구매 구성표·일자별 운영안·후보 풀 CSV 및 Markdown 다운로드 지원

## 계산 기준

```text
총예산 상한 = 정확한 인원수 × 교육일수 × 10,000원
하루 다과 총량 = ceil(인원수 × 3개 × 1.10)
후보 풀 크기 = min(16, 6 + 2 × 교육일수)
```

## 실행

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

## 테스트

```bash
python -m unittest discover -s tests -v
```

## 배포

Streamlit Community Cloud의 Main file path를 다음으로 설정합니다.

```text
snack_budget_streamlit/app.py
```

기존 저장소의 `snack_budget_streamlit` 폴더에 이 배포본 파일을 덮어쓴 뒤
커밋하고 푸시하면 됩니다.
