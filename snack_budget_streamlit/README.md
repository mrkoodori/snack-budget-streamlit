# 예산 맞춤형 교육용 다과 추천 Streamlit 앱 v3

사내 교육, 워크숍, 세미나, 연수, 설명회에서 여러 명에게 빠르게 배포하기 좋은
가성비 중심의 낱개포장 과자와 음료를 추천하는 웹앱입니다.

## 이번 수정 핵심

- 기존 **교육시간(2시간 단위 등)** 입력을 제거했습니다.
- **교육일수 1~5일** 입력을 추가했습니다.
- 총예산 상한을 `인원수 × 교육일수 × 1인 1일 예산`으로 계산합니다.
- 1인 1일 예산 상한은 최대 10,000원이며, 5일 교육의 1인 누적 상한은 50,000원입니다.
- 10,000원은 지출 목표가 아니라 상한이며, 추천 구성은 필요한 범위에서 가성비 있게 산정합니다.
- 장기차수는 일자별 다과 조합을 순환해 같은 구성이 계속 반복되지 않도록 합니다.
- 20~30대와 40~50대 추천 차이를 화면에서 설명합니다.
- 연령대는 선호를 단정하지 않고 추천 우선순위를 조정하는 참고값으로만 사용합니다.
- `달콤하고 간편한 구성`, `담백함을 더한 균형 구성`, `호불호 적은 기본 구성`을 선택할 수 있습니다.
- 구매 구성표와 별도로 **일자별 운영안 CSV**를 다운로드할 수 있습니다.

## 계산 방식

```text
총 제공 기준(인일) = 인원수 × 교육일수
총예산 상한 = 인원수 × 교육일수 × 1인 1일 예산
다과 목표 수량 = 일자별 인원수 × (1 + 여유율) × 해당 품목 제공일수
생수 목표 수량 = 인원수 × 교육일수
```

예시:

```text
30명 × 5일 × 10,000원 = 총예산 상한 1,500,000원
1인 누적 예산 상한 = 5일 × 10,000원 = 50,000원
```

## 로컬 실행

Python 3.10 이상을 사용합니다. 권장 버전은 Python 3.12입니다.

```bash
python -m venv .venv
```

macOS/Linux:

```bash
source .venv/bin/activate
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

설치 및 실행:

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 기본적으로 `http://localhost:8501`을 엽니다.

## 가격 데이터 수정

`catalog.py`의 각 상품 `pack_options`를 수정하면 추천 금액이 바뀝니다.

```python
PackOption(24, 12_500)
```

위 값은 `24개입 묶음의 예상 가격이 12,500원`이라는 뜻입니다.
가격은 실시간 판매가가 아니므로 월 1회 또는 행사 전에 점검하는 방식을 권장합니다.

## 운영상 주의

- 쿠팡 검색 결과의 판매가, 입수량, 재고, 배송일은 수시로 바뀔 수 있습니다.
- 앱의 가격은 구매 판단을 돕는 추정치이며 결제 금액을 보장하지 않습니다.
- 상품 상세 페이지에서 개별포장 여부, 유통기한, 여름철 보관 조건을 확인하세요.
- 쿠팡 페이지 스크래핑이나 자동 주문 로직은 포함하지 않았습니다.
