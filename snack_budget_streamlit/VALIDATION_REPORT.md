# 검증 결과

## 적용 기준

- 교육일수: 최소 1일, 최대 5일
- 1인 1일 예산 입력 범위: 3,500원~10,000원
- 기본 1인 1일 예산 상한: 10,000원
- 5일 기준 1인 누적 예산 상한: 50,000원
- 총예산 상한: `인원수 × 교육일수 × 1인 1일 예산`

## 자동 검증 결과

- Python 문법 검사: 통과
- 단위 테스트: 13개 통과
- 조건 조합 검증: 7,500개 통과
  - 인원수: 1명 / 5명 / 10명 / 30명 / 100명
  - 교육일수: 1~5일
  - 1인 1일 예산: 3,500원 / 5,000원 / 10,000원
  - 음료 구성: 전체 5종
  - 연령대: 전체 5종
  - 구성 성향: 전체 4종

## 공통 검증 조건

- 전체 예상 합계가 총예산 상한을 넘지 않음
- 일자별 운영안 개수가 교육일수와 일치
- 쿠팡 검색 링크 형식 정상
- 기본값 10,000원 적용 정상
- 10,000원 초과 예산 입력 차단 정상
- 30명 × 5일 × 10,000원 = 1,500,000원 계산 정상
- 5일 기준 1인 누적 상한 50,000원 계산 정상
