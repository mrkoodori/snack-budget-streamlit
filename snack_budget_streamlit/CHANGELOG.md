# 변경사항

## v3 — 1인 1일 예산 상한 10,000원 적용

### 예산 입력
- `1인 1일 예산 상한`의 최대값을 5,000원에서 10,000원으로 확대
- 기본 선택값을 10,000원으로 변경
- 입력 가능 범위: 3,500원~10,000원
- 최대 5일 교육 시 1인 누적 예산 상한은 50,000원
- 총예산 상한 계산식은 `인원수 × 교육일수 × 1인 1일 예산` 유지

### 예시
- 30명 × 1일 × 10,000원 = 300,000원
- 30명 × 5일 × 10,000원 = 1,500,000원
- 100명 × 5일 × 10,000원 = 5,000,000원

### 검증
- 기본 예산값 10,000원 검증 추가
- 10,000원 초과 입력 차단 테스트 추가
- 1~5일 전체 조합의 총예산 상한 준수 재검증

## v2 — 교육일수 기준 개편

### 입력 화면
- `교육 시간` 선택값 삭제
- `교육일수` 1~5일 입력 추가
- `1인 예산 상한`을 `1인 1일 예산 상한`으로 명확화
- `구성 성향` 선택 추가
- 입력 중 총예산 상한 미리보기 추가

### 계산 로직
- 총예산: `인원수 × 교육일수 × 1인 1일 예산`
- 생수: `인원수 × 교육일수` 최소 확보
- 다과: 일자별 인원수에 여유율을 적용한 뒤 제공일수만큼 합산
- 1~5일 일자별 순환 조합 생성
- 총예산 12% 수준의 예비비를 우선 확보하고, 불가할 때만 절대 상한 안에서 조정
- 소규모 묶음 단가가 예산을 압박하면 보조 음료를 경제적인 대안으로 자동 조정

### 결과 화면
- 총 제공 기준(인일), 1인 누적 상한, 예상 1인 1일 비용 표시
- 연령대별 추천 차이 설명 추가
- 일자별 운영안 표 추가
- 구매표에 제공일·목표 수량 추가
- 일자별 운영안 CSV 다운로드 추가

### 테스트
- 교육일수별 총예산 계산
- 5일 순환 구성
- 음료 제외
- 저예산 복수 음료 구성
- 쿠팡 검색 링크
- 교육일수 범위 검증 테스트 추가
